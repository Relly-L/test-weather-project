Основан на [FUNCTIONAL_REQUIREMENTS.md](FUNCTIONAL_REQUIREMENTS.md) и [TECH_REQUIREMENTS.md](TECH_REQUIREMENTS.md). Статус: этапы 1–5 выполнены, репозиторий инициализирован локально; осталось создать удалённый репозиторий, запушить и включить Pages.

- Фоновые изображения в `public/backgrounds/` (8 штук, авторы в [CREDITS.md](CREDITS.md)).

## Этапы
1. **Каркас проекта.** Next.js (App Router, TypeScript) вручную в существующей папке (`create-next-app` не любит непустую). `next.config`: `output: 'export'`, `images.unoptimized`, `basePath`/`assetPrefix` из переменной окружения (в проде `/test-weather-project`). Скрипты `dev`, `build`, `lint`.
2. **Локализация.** Словари `en.json`, `uk.json`; выбор по `navigator.languages`, запасной `en`; обновление `<html lang>`.
3. **Данные.** Модули: геолокация браузера, определение по IP (выбрать сервис из ipwho.is и ipapi.co, проверив HTTPS, лимиты и CORS), запрос текущей погоды Open-Meteo (температура, код погоды, признак день/ночь), функция «код погоды → фон». Таймауты и обработка ошибок.
4. **Интерфейс.** Одна страница, Mobile First: фон на весь экран, крупная температура по центру, состояния загрузки, «нужна геолокация» и ошибки с кнопкой Retry, переводимые тексты.
5. **Проверка.** Юнит-тесты на соответствие кода фону и выбор локали; `next build`; просмотр в браузере на мобильной и широкой ширине; проверка отказа в геолокации и сбоя сети.
6. **Репозиторий и деплой.** `git init`, `.gitignore`, первый коммит; публичный репозиторий `test-weather-project` на личном аккаунте; GitHub Actions workflow для Pages; проверка живого адреса.
7. **Завершение.** `README.md`, `CLAUDE.md` (ссылки на документы), перепроверка лицензий фото.

## Решения, которые принимаются по ходу
- Менеджер пакетов (по умолчанию npm) и версия Node (LTS).
- Выбор IP-сервиса.
- Формат температуры: целое число с округлением и знаком минус.

## Риски
- IP-определение отдаёт IP пользователя стороннему сервису (отразить в README).
- Лимиты бесплатных API; кэширование запросов не предусмотрено.
- Мигание языка при гидрации из-за статической сборки на английском.
- Создание репозитория: в этой среде нет `gh`, потребуется установить его или создать репозиторий вручную.
