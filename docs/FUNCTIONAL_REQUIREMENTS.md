# Weather — функциональные требования

Статус: черновик, версия 1 («абсолютный минимализм»). Технические требования: [TECH_REQUIREMENTS.md](TECH_REQUIREMENTS.md).

## Общее
- Язык интерфейса: по языку браузера, по умолчанию английский; переключателя языка нет (см. [TECH_REQUIREMENTS.md](TECH_REQUIREMENTS.md), раздел «Локализация»). Переводимые тексты: загрузка, ошибки, просьба включить геолокацию, кнопка «Retry».
- Одна страница, подход Mobile First: сначала мобильная вёрстка, затем адаптация под широкие экраны.
- Минимализм: на экране только текущая температура и фон.

## Экран
- По центру крупными цифрами текущая температура в °C.
- Фон соответствует текущей погоде: статичная картинка (ясно, облачно, дождь, снег, гроза, туман; день и ночь). Анимации отложены, см. [IDEAS.md](IDEAS.md).
- Тип фона определяется по коду погоды (WMO weather code) и признаку день/ночь из ответа Open-Meteo.

### Соответствие кода погоды и фона (WMO)
| Фон | Коды |
|---|---|
| `clear-day` / `clear-night` | 0, 1 (по признаку день/ночь) |
| `cloudy` | 2, 3 |
| `fog` | 45, 48 |
| `rain` | 51–57, 61–67, 80–82 |
| `snow` | 71–77, 85–86 |
| `thunderstorm` | 95, 96, 99 |
| `default` | любой другой код или нет данных |

## Определение местоположения
1. Запрос геолокации браузера (Geolocation API).
2. Если пользователь отказал или произошла ошибка, приблизительные координаты по IP.
3. Погода по полученным координатам запрашивается у Open-Meteo.

## Состояния
- Загрузка: нейтральный фон и индикатор.
- Координаты не определены (отказ в геолокации и сбой определения по IP): экран с просьбой включить геолокацию в браузере и кнопкой «Повторить».
- Ошибка запроса погоды: короткое сообщение и кнопка «Повторить».

## Вне рамок версии 1
Поиск города, прогноз, влажность, ветер, смена единиц, темы, сохранение выбора.
