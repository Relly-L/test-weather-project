## Подтверждено

### Проект
- Небольшой минималистичный сайт о погоде.
- Папка проекта: `E:\AI\Claude\Projects\Weather`.
- Next.js задуман как задел на будущее, к тому же он знаком автору.

### Стек
- Next.js, App Router.
- TypeScript.
- Режим SSG: `output: 'export'` в `next.config`, на выходе статический каталог `out/`.
- Серверных компонентов с рантайм-данными, API routes и middleware нет: всё это несовместимо со статическим экспортом.

### Фон
- Статичные изображения в `public/` (`next/image` при статическом экспорте требует `images.unoptimized: true`, поэтому готовить файлы нужно заранее).
- 8 слотов: `clear-day`, `clear-night`, `cloudy`, `rain`, `snow`, `thunderstorm`, `fog`, `default` (запасной, нейтральное небо).
- Формат: WebP, портрет около 1080×1920, до ~200 КБ на файл; `object-fit: cover`.
- Источник: Unsplash (лицензия Unsplash: бесплатно, в том числе для коммерческого использования, атрибуция не обязательна). Файлы скачиваются и лежат в репозитории, без hotlinking.
- Только обычные фото Unsplash, без пометки Unsplash+ (платный уровень). Лицензию проверять на странице каждого фото.
- Автор и ссылка на каждое фото записываются в `docs/CREDITS.md`.
- Кандидаты (коллекции для выбора): [Clear Sky Day](https://unsplash.com/@rbtech/collections), [Startrails and Comets](https://unsplash.com/collections/9336269/startrails-and-comets), поиск [thunderbolt](https://unsplash.com/s/photos/thunderbolt), [dark weather](https://unsplash.com/s/photos/dark-weather).

### Локализация
- Поддержка нескольких локалей; язык выбирается по языку браузера (`navigator.languages`), без переключателя в интерфейсе.
- Локали первой версии: `en` (английский) и `uk` (украинский). Код именно `uk`: так язык называется в стандарте и в `navigator.languages` (`ua` — это код страны, он не сработает).
- Язык по умолчанию: английский (`en`), в том числе когда язык браузера не поддерживается.
- Определение локали выполняется на клиенте: при статическом экспорте нет middleware и заголовка `Accept-Language`, а встроенная i18n-маршрутизация Next.js не работает. Отдельные URL по локалям не нужны.
- Статический HTML отдаётся на английском, после гидрации подменяются тексты под локаль пользователя (возможно кратковременное мигание, учесть при реализации).
- Тексты хранятся в словарях (`en.json` и т. д.), без тяжёлых i18n-библиотек. Эти же словари используются для атрибута `<html lang>`.
- Числа и единицы форматируются через `Intl.NumberFormat` с учётом локали.

### Данные
- Погода: Open-Meteo (бесплатный, без API-ключа).
- Координаты: Geolocation API браузера, при отказе или ошибке — определение по IP через бесплатный HTTPS-сервис (кандидаты: ipwho.is, ipapi.co; выбрать при реализации).
- Запросы выполняются **на клиенте** (в браузере), потому что статическая сборка не знает погоду на момент запроса.
- Секретов и переменных окружения с ключами быть не должно.

### Репозиторий и развёртывание
- Репозиторий: `test-weather-project` на личном GitHub-аккаунте автора, публичный (GitHub Pages на публичных репозиториях бесплатен). Секретов в репозитории быть не должно.
- Хостинг первой версии: GitHub Pages (статический каталог `out/`).
- Публикация через GitHub Actions: сборка `next build` и деплой артефакта `out/` на Pages (Settings → Pages → Source: GitHub Actions).
- Если репозиторий публикуется как проектная страница (`<user>.github.io/<repo>/`), в `next.config` нужны `basePath` и `assetPrefix` = `/test-weather-project` (задавать через переменную окружения, чтобы локально и при смене домена работало без правок); пути к фонам строятся с учётом `basePath` (при `images.unoptimized` и обычных `<img>`/CSS Next его сам не добавляет). Для пользовательской страницы (`<user>.github.io`) или своего домена `basePath` не нужен.
- При деплое через GitHub Actions Jekyll не используется, поэтому `.nojekyll` не нужен (понадобится только при публикации из ветки).
- Домен: желателен собственный, но только бесплатный. Начинаем с адреса GitHub Pages (`<user>.github.io/<repo>`, с `basePath`). Позже можно подключить бесплатный поддомен через CNAME и поле Custom domain в настройках Pages; тогда `basePath` убирается.
- Кандидаты на бесплатный поддомен (условия и сроки проверить на официальных страницах): [is-a.dev](https://github.com/is-a-dev/register), [eu.org](https://nic.eu.org), [Open Domains](https://github.com/open-domains/register). [js.org](https://github.com/js-org/js.org) подходит только проектам, связанным с JavaScript, и для личных страниц больше не выдаётся.
- Никаких серверных зависимостей в рантайме; переход на другой статический хостинг должен сводиться к смене `basePath`.
